# infra/ — опциональный хостинг на DigitalOcean App Platform

**Это не обязательный шаг.** Основной способ публикации сайта — GitHub
Pages (бесплатно, ноль настройки Terraform, см. корневой `README.md`).
Этот модуль существует по двум причинам:

1. Как альтернативная точка развёртывания, если вы хотите держать хостинг
   в аккаунте DigitalOcean, который у вас уже есть.
2. Как рабочий пример IaC внутри самого портфолио — то, что реально
   оценит технический интервьюер, открыв репозиторий.

## Стоимость (проверено на июль 2026)

| Вариант | Стоимость |
|---|---|
| GitHub Pages | $0, без ограничений по трафику для личного сайта |
| DO App Platform, static site | $0 за первые 3 приложения, 1 GiB исходящего трафика/месяц на приложение; сверх лимита — $0.02/GiB |
| DO App Platform, 4-е и последующие static-site приложения | $3/месяц за приложение |

Для одного портфолио с невысокой посещаемостью DO App Platform остаётся
бесплатным. Если ожидаете много трафика (например, пост с сайта попал
в топ Hacker News) — у GitHub Pages запас по трафику больше, это стоит
учитывать.

## Что нужно перед запуском

1. Токен DigitalOcean API (Settings → API → Generate New Token, права на
   запись).
2. Репозиторий `portfolio` уже должен существовать на GitHub (DO App
   Platform подключается к нему по имени `username/portfolio`).

## Запуск

```bash
cd infra
terraform init

# Токен передаём через переменную окружения, а не через файл:
export TF_VAR_do_token="dop_v1_xxxxxxxxxxxxxxxx"
export TF_VAR_github_repo="your-username/portfolio"

terraform plan
terraform apply
```

После первого `apply` DigitalOcean попросит авторизовать доступ к
репозиторию через GitHub App — это делается один раз в веб-интерфейсе
DigitalOcean по ссылке, которую покажет `terraform apply` при первом
запуске (или заранее в Control Panel → Apps → GitHub → Install & Authorize).

## Домен

Если используете `domain_name`, добавьте DNS-запись у вашего регистратора,
указывающую на приложение (DO покажет нужную CNAME-запись в выводе после
`apply` или в панели управления). Автоматический TLS-сертификат
DigitalOcean выпускает сам.

## Удаление (чтобы не платить, если передумали)

```bash
terraform destroy
```

Так как компонент — только `static_site`, само приложение и так бесплатно;
`destroy` нужен, только если хотите освободить один из трёх бесплатных
слотов для другого проекта.
